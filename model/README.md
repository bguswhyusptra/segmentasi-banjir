## Cara Setup Model:
1. Download keempat file model dari link di atas
2. Letakkan semua file `.h5` ke dalam folder ini (`model/`)
3. Pastikan nama file sesuai dengan yang tertera di atas
4. Jalankan aplikasi dengan `python app.py`
